# Creating Hugo posts from Telegram image uploads

## When to use

The user sends images via Telegram to be added to the Hugo site at `/home/uiyx/projects/paneva-art`. The images are cached with autogenerated filenames — **the original filename is lost**.

## Important limitation

**I CANNOT see the original filename** — Telegram's image cache renames files to `img_<hash>.jpg`. Therefore I must ask the user for the painting's metadata (title, technique, size, price) unless they've already provided it in the same message.

## Steps

1. **Use the cached image** from Telegram (under `~/.hermes/profiles/qna-web/cache/images/`). Copy this file directly as `images/featured.jpg`. Do NOT look for the image in `~/documents/novi-qna/` — the Telegram files are the only source.

2. **Ask the user for metadata** if not already provided — title, technique, size, price.

3. **Parse the user's answer** for:
   - **Title** (in Bulgarian quotes „ „)
   - **Technique** (масло, акрил, акварел, акварел/акрил, въглен, туш, молив)
   - **Size** (e.g. 35×50 cm, 45×55 cm)
   - **Price** (e.g. 60 евро) or status („продадена“ / „неналичен“)

4. **Create page bundle** in `content/bg/posts/`:
   - Folder: `„{Title}“ {technique}{size}{price}/`
   - Subfolder: `images/` with `featured.jpg` (copied from Telegram cache)

5. **Write index.md** following existing conventions:
   ```yaml
   ---
   title: '„{Title}“'
   slug: '{latin-slug}'
   tags: ['{Technique}']
   summary: 
   description:
   expiryDate: ''
   translationKey:
   draft: false
   type:
   layout: 'single'
   ---
   ```
   ```
   „{Title}“, {technique}, размер {X} на {Y} см., цена {Z} евро
   ```

   `summary` must be populated with same text as code block description.

6. **Validate** with `hugo --quiet`.

7. **Commit** with message: `Добавена публикация „{Title}“ — {technique}, ...`

## Tags convention

- `['Масло']` for масло
- `['Aкварел']` for акварел (with capital A — site uses 'Aкварел')
- `['Aкрил']` for акрил
