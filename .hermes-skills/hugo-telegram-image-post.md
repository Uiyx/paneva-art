# Creating Hugo posts from Telegram image uploads

## When to use

The user sends images via Telegram to be added to the Hugo site at `/home/uiyx/projects/paneva-art`. **The filename always contains the painting's metadata** — do not ask for details.

## Filename format

Files come from `~/documents/novi-qna/`. The filename structure is:

```
Title, technique, size, price- XX евро.jpg/png
```

**Examples:**
- `„Старото менче“ масло 45на55 120евро` → title: „Старото менче“, technique: масло, size: 45×55 cm, price: 120 евро
- `Разтопени хоризонти, акварел, размер 35 на 50 см., цена-80 евро.png` → title: Разтопени хоризонти, technique: акварел, size: 35×50 cm, price: 80 евро
- `„Земя и небе“, акварел, акрил, цена- 60 евро.jpg` → title: Земя и небе, technique: акварел/акрил, price: 60 евро

## Steps

1. **Inspect the cached image** from the Telegram upload (under `~/.hermes/profiles/qna-web/cache/images/`) via `vision_analyze()` if you need to identify which file in `~/documents/novi-qna/` it matches. The cached filename is autogenerated — ignore it. Match by visually comparing with files in `~/documents/novi-qna/`.

2. **Parse filename** for:
   - **Title** (text before first comma or „ „ quotation marks)
   - **Technique** (масло, акрил, акварел, акварел/акрил, въглен, туш, молив)
   - **Size** (e.g. 35×50 cm, 45×55 cm, or 45 на 50)
   - **Price** (e.g. 60 евро, 80 евро, or „продадена“ / „неналичен“)
   - For mixed technique like "акварел, акрил" → tag with the primary technique

3. **Create page bundle** in `content/bg/posts/` with folder name format:
   ```
   „{Title}“ {technique} {size} {price}.md
   ```
   - Folder: `„{Title}“ {technique}{size}{price}/`
   - Subfolder: `images/` with `featured.jpg` (renamed from the source file)

4. **Write index.md frontmatter** following existing conventions:
   ```yaml
   ---
   title: '„{Title}“'
   slug: '{generated-latin-slug}'
   tags: ['{Technique capitalised}']
   summary:
   description:
   expiryDate: ''
   translationKey:
   draft: false
   type:
   layout: 'single'
   ---
   ```
   ```
   „{Title}“, {technique}{, size}..., цена {price}
   ```

   IMPORTANT: `summary` field must be populated with same text as the code block description.

5. **Copy image** from source to `images/featured.jpg`. Convert PNG to JPG if needed.

6. **Validate** with `hugo --quiet`.

7. **Commit** with message: `Добавена публикация „{Title}“ — {technique}, ...`

## Tags convention

- `['Масло']` for масло
- `['Aкварел']` for акварел (with главно A — the site uses 'Aкварел' not 'Акварел')
- `['Aкрил']` for акрил
- `['Масло', 'Пейзаж']` etc. for mixed tags

## Important notes

- Site is at `/home/uiyx/projects/paneva-art`, Hugo v0.163.1, theme Qna
- Posts use Bulgarian quotes „ „ in titles and descriptions
- Description format in code block: `„{Title}“, {technique}, размер {X} на {Y} см., цена {Z} евро`
- Do NOT push unless asked — just commit locally
