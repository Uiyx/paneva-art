# Creating Hugo posts from Telegram image uploads

## When to use

The user sends images via Telegram to be added to the Hugo site at `/home/uiyx/projects/paneva-art`. The images are cached with autogenerated filenames — **the original filename is lost**. Therefore, I must always ask the user for metadata (title, technique, size, price) unless they have explicitly provided it in the same message or in a previous one that clearly refers to the current image.

## Important limitation

**I CANNOT see the original filename** — Telegram's image cache renames files to `img_<hash>.jpg`. Therefore I must ask the user for the painting's metadata (title, technique, size, price) unless they've already provided it in the same message.

## Steps

1. **Use the cached image** from Telegram (under `~/.hermes/profiles/qna-web/cache/images/`). Copy this file directly as `images/featured.jpg`. Do NOT look for the image in `~/documents/novi-qna/` — the Telegram files are the only source.

2. **Ask the user for metadata** if not already provided — title, technique, size, price.

3. **Parse the user's answer** for:
   - **Title** (in Bulgarian quotes „ „)
   - **Technique** (масло, акрил, акварел, акварел/акрел, въглен, туш, молив)
   - **Size** (e.g. 35×50 cm, 45×55 cm, 20x50 см.) — keep the exact format the user provides (do not convert "x" to " на " unless the user wrote it that way)
   - **Price** (e.g. 60 евро) or status („продадена“ / „неналичен“)

4. **Create page bundle** in `content/bg/posts/`:
   - Folder: `„{Title}“ {technique}{size}{price}/`
   - Subfolder: `images/` with `featured.jpg` (copied from Telegram cache)

5. **Write index.md** following existing conventions:
   ```yaml
   ---
   title: '„{Title}“'
   slug: '{latin-slug}'
   tags: ['{Technique}']
   summary: 
   description:
   expiryDate: ''
   translationKey:
   draft: false
   type:
   layout: 'single'
   ---
   ```
   ```
   „{Title}“, {technique}, размер {size} см., цена {price} евро
   ```

   `summary` must be populated with same text as code block description.

6. **Validate** with `hugo --quiet`.

7. **Commit** with message: `Добавена публикация „{Title}“ — {technique}, ...`

## Tags convention

- `['Масло']` for масло
- `['Aкварел']` for акварел (with capital A — site uses 'Aкварел')
- `['Aкрил']` for акрил

## Pitfalls

- **Lost Telegram Filenames:** Telegram caches images with autogenerated filenames (e.g., `img_abcde12345.jpg`), discarding the original filename provided by the user. This means I **cannot** infer the painting's metadata (title, technique, size, price) from the filename. Always ask the user for this information, even if their initial message implied it was in the filename.
- **Image Source Confusion:** Do NOT attempt to find the image in `~/documents/novi-qna/`. The Telegram-sent image (cached locally by Hermes) is the definitive source.
- **Missing Size:** If the user states a painting has no size, do not include a size in the post folder name or the description block.
